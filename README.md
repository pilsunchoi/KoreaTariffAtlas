# 한국 관세 아틀라스 · Korea Tariff Atlas

HSK 10단위 코드 하나하나에 대해 **어느 나라에서 들여오면 관세가 얼마인지**, 그 세율이
**20년 동안 어떻게 바뀌었는지**, 그리고 **실제로 얼마가 그 세율을 만났는지**를 함께 보여 준다.

**<https://pilsunchoi.github.io/KoreaTariffAtlas/>**

> 이 화면의 세율은 참고용이며 법적 효력이 없다. 실행세율은 관세법 제50조를 해석해 만든
> 파생값이다. 세액 계산이나 수입신고에는 관세법 별표 관세율표와 해당 규정의 원문을
> 확인해야 한다. → [NOTICE.md](NOTICE.md)

## 관용명 사전

관세율표의 법정 품명만 훑으면 「승용차」로는 아무것도 안 나온다 — 제8703호의 법정 표현은
「승용자동차와 그 밖의 사람을 수송할 수 있도록 주로 설계된 차량」이다.
[`data/관용명_사전.csv`](data/관용명_사전.csv)가 그 틈을 메운다.

```
term,aliases,target,note
승용차,자동차|세단|SUV|신차|중고차,8703,「차」는 녹차와 겹쳐 뺐다
```

293항목·검색어 917개로 HSK 코드의 41.7%, 2025년 수입액의 **80.8%**를 덮는다.
`target`은 호(4자리)·소호(6자리)·10단위를 `|`로 여럿 쓸 수 있고 접두사로 해석한다.
고치면 `scripts/build_synonyms.py`를 다시 돌린다 — 없는 대상, 코드 0개, 말 중복,
이미 법정 품명으로 찾아지는 말을 잡아 [`data/관용명_사전_검증.csv`](data/관용명_사전_검증.csv)에 적는다.
넓힐 곳은 [`data/관용명_사전_빈칸.csv`](data/관용명_사전_빈칸.csv)(아직 사전이 없는 호를 수입액 순으로)에 있다.

검색 쪽 규칙 둘. 순위는 ① 코드 접두 일치 ② 사전이 지목한 코드 ③ 그 밖의 글자 일치 순이고,
같은 층에서는 수입액이 큰 코드가 앞이다(없으면 「콜라」가 「콜라주」에 밀린다).
사전 힌트는 앞걸림이 있으면 뒷걸림을 버린다(없으면 「다이아몬드」가 「아몬드」를 끌어온다).

## 디자인 — 아틀라스 계열

대시보드를 두 갈래로 나눈다. **소개형**은 「이 자료가 무엇이고 어떻게 만들었나」에 답하고
([KCSDB2](https://pilsunchoi.github.io/KCSDB2/) · [KCSTARIFF](https://pilsunchoi.github.io/KCSTARIFF/)),
**아틀라스형**은 「이 자료로 무엇을 보나」에 답한다
([Trade Network](https://pilsunchoi.github.io/TradeNetworkAtlas/) ·
[Maritime Pulse](https://pilsunchoi.github.io/MaritimePulseAtlas/) · 이것).

계열 정본은 [`src/assets/atlas-base.css`](src/assets/atlas-base.css) 하나다. 표면이 둘이다.

```
:root                       → 다크. 탐색 도구용(atlas.html)
:root[data-surface="light"] → 라이트. 읽는 문서용(코드별 페이지)
```

자동 반전이 아니라 표면마다 고른 값이다. 글꼴은 라틴과 한글을 나눠 맡긴다 —
Instrument Serif·Sans에는 한글이 없어 한글은 IBM Plex Sans KR이 받는다.
계열색은 `--series-1..3`, 순차 램프는 `--seq-100..700`(100이 표면에 가깝고 700이 가장 두드러진다)이며,
램프 방향이 표면마다 반대라 칸 위 글자색은 박아 두지 않고 칸 색의 밝기로 정한다.
SVG 색은 표현속성이 아니라 `style` 속성으로 넘긴다(엔진에 따라 `fill="var(--x)"`가 안 먹는다).

**다른 아틀라스에 쓸 때는 이 파일을 복사한다.** CDN 링크로 묶지 않는다 —
한 곳이 깨지면 전부 깨지고, 모든 대시보드가 자기완결형이라는 원칙과도 어긋난다.

## 다시 만들기

`docs/` 아래는 전부 생성물이다. 세율·무역통계 DB는 이 저장소에 없고 두 저장소에서 읽는다
([KCSTARIFF](https://github.com/pilsunchoi/KCSTARIFF) · [KCSDB2](https://github.com/pilsunchoi/KCSDB2)).

```
python scripts/prep_names.py      # 관세율표 HWP → data/hs_names.json        (10초)
python scripts/build_synonyms.py  # 사전 검증 → docs/synonyms.js             (1분)
python scripts/prep_data.py       # 대시보드 자료 → docs/atlas-data.js       (4분)
python scripts/build_pages.py     # 코드별 페이지 → docs/hs/                 (1분 반)
```

순서대로 돌린다. `build_pages.py`는 `docs/hs/`만 비우고 앞 단계의 산출물은 건드리지 않는다.
DB가 다른 자리에 있으면 환경변수로 알려 준다 — `KCSTARIFF_DB`, `KCSDB2_DB`,
`TARIFF_SCHEDULE_HWP`([`scripts/paths.py`](scripts/paths.py)).

주소가 바뀌면 `scripts/build_pages.py`의 `BASE` 한 줄만 고친다(canonical·og:url·sitemap이 따라간다).

`build_pages.py`는 끝에서 **내부 링크 105,886개를 전수 검사**하고, 하나라도 깨지면 `exit 1`이다.

### 관세율표 HWP 파서

표의 행마다 칸 수가 달라 4칸씩 건너뛰면 어긋난다.

```
8535 | 　  | 전기회로의 개폐용·보호용…   | 　   ← 소호가 여럿인 호: 호 이름 행이 따로 있다
2709 | 00 | 석유와 역청유(원유로 한정한다) | 　   ← 소호가 '00' 하나뿐: 호 이름 행이 없다
8109 | 2  | 지르코늄의 괴(塊), 가루           ← 소호그룹 행: 세율 칸이 없어 3칸뿐
```

보폭을 고정하지 않고 「행 머리」를 먼저 찾아 그 사이를 한 행으로 보고, 호 이름 행이 없는 호는
소호에서 이름을 올려 채운다. 류 이름은 「주:」 앞까지 여러 줄을 잇는다.
스크립트 끝에서 세율 DB와 대조해 **빈 곳 0**(류 96 · 호 1,228 · 소호 5,612)을 확인한다.

## 이 자료가 답하지 못하는 것

- **명목이지 실제가 아니다.** 「명목 관세액」은 법정 실행세율 × 수입액이다. 감면·면세·환급·보세가
  빠져 있어 실제 관세 수입보다 훨씬 크다.
- **FTA 세율은 신청했을 때 적용될 수 있는 세율**이지 실제로 적용된 세율이 아니다.
  원산지증명을 못 받아 MFN을 낸 물량이 섞여 있어 「깎인 몫」은 상한 추정이다.
- **협정 일곱 개만** 담겨 있다(중국·EU·미국·아세안·인도·베트남·캐나다 + APTA).
  호주·RCEP·영국·중미 등은 원자료 화면에 열이 없어 빠졌다.
- **1월 1일 기준**이라 하반기에 지정되는 할당관세 같은 연중 변경은 놓칠 수 있다.
- **검색은 사전이 덮는 만큼만 된다.** 중간재·부품은 법정 명칭이 곧 업계 용어라 사전이 얇다.
